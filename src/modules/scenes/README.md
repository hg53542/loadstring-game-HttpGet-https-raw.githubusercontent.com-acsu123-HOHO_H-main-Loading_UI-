# Módulo `scenes` — Cenários 3D

**Status:** não iniciado — etapa 6.

Cenários previstos: quarto gamer, taverna, palácio demoníaco, arena de batalha, masmorra.

**Regras:** cada cenário é um componente R3F independente, com orçamento de desempenho
(alvo: 30+ FPS em GPU integrada Intel Iris Xe), iluminação própria compatível com os
presets de luz, e somente assets próprios ou com licença registrada em `docs/LICENCAS.md`.
